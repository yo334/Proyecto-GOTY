# Proyecto GOTY

## ¿De qué trata esto?
Este es un proyecto web escolar para la materia Laboratorio de Aplicaciones. 
El objetivo principal es realizar una página web que muestra los ganadores 
hisotoricos del premio GOTY de forma clara y ordenada, ademas se busca 
implementar un sistema de votación popular para que la gente elija a los 
ganadores de distintos premios de la seremonia a lo largo de los años, 
todas esta votaciones seran guardadas en una base de datos para su posterior
analisis, cuando tenga suficientes datos se mostrara segun la gente cuales fueron
los distintos ganadores.

## Tecnologías que usamos
- HTML5 (Estructura)
- CSS (Estilos, metidos en la carpeta `/Css`, lo se, totalmente inesperado)
- Vanilla JavaScript (Lógica, metido en la carpeta `/js`)

## Reglas de las carpetas
- Todos los estilos van separados por páginas en la carpeta `/Css`.
- Nada de frameworks
