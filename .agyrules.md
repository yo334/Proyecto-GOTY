# Reglas de Código para la IA

- Estilo de código: Mantenelo simple y nivel principiante/intermedio. No uses sintaxis hiper compleja de JavaScript que sea difícil de entender para un estudiante.
- Idioma: Escribí los comentarios del código en español.
- CSS: No uses estilos en línea (adentro del HTML). Todo tiene que ir a sus respectivos archivos en la carpeta `/Css`.
- Estructura: Antes de crear un archivo nuevo, revisá si no tiene más sentido meter el código en uno de los archivos que ya existen.
- siempre debes buscar la sintaxsis simple, y con esto me refiero a que si hay una forma mas facil de que el codigo se entienda a simple vista pero hace que toma el triple de lineas, lo hagas igualmente, siempre prioriza los facilmente interpretable
